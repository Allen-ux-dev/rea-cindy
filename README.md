# REA for Cindy

第三方 REA 本地分析插件，把 REA 的工具目录、独立调查和证据管理接入 Cindy。

**当前版本：0.1.3（测试版）** · **仅 macOS Apple Silicon** · **Cindy 0.1.115 或更新版本**

## 下载与安装

1. 打开 [v0.1.3 下载页面](https://github.com/Allen-ux-dev/rea-cindy/releases/tag/v0.1.3)。
2. 在 Assets 中下载 `rea-cindy-0.1.3.cindy`，不要下载 GitHub 自动生成的 Source code ZIP。
3. 在 Cindy 的插件页面导入 `.cindy`，按宿主提示确认权限并启用。
4. 打开插件工作台，检查环境并运行随包样例；在本地项目对话中使用 `$rea`。

可用同页的 `SHA256SUMS.txt` 核验文件。

## 功能

- 内置 REA 6.8.0 和本地 Node 运行环境，无需租用服务器。
- 保留 229 个原版工具的完整目录与参数描述。
- 独立调查、证据查询、大结果分页及完整结果导出。
- 红橙主题工作台、首次使用引导、可选引擎检查和配置说明。

## 验证范围与限制

核心静态分析和证据工作流已经测试，涵盖 JavaScript/Electron、IPA、Mach-O、签名与部分原生元数据。229 个工具并非全部端到端实测。部分样本记录来自使用者提供的实测报告。

Ghidra、Hopper、IDA、Android、浏览器及调试等能力需要对应的外部环境和授权。Frida 原生组件未随包提供；ILSpy 属于外部反编译输出导入流程。路径检查通过不等于实际分析成功。

动态分析可能执行程序、读写文件或连接目标。仅分析你拥有或获得授权的目标。已保存证据留在本机，卸载不会自动删除这部分数据。
